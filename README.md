# rclone personal

Aplicación personal de rclone que uso solo yo para respaldar mis archivos en mi propio Google Drive desde mi computador.

## Privacidad

Esta app accede únicamente al Google Drive de su único usuario (el dueño de esta cuenta) para guardar y leer sus propios respaldos. No recopila, no comparte y no vende datos personales. Los datos solo viajan entre mi computador y mi Google Drive.

## Terminos

Uso personal y no comercial, sin garantías. Esta app no está disponible para otras personas.
